DADOS

Exportar e fazer backup

Exporte os resultados com pontos válidos e indicador de tribo sem pontuação. Guarde cópias regulares do arquivo bloodline.db.

O arquivo JSON é uma cópia portátil de referência dos dados. A restauração automatizada não está incluída nesta versão. Para restauração integral, faça backup do banco SQLite.
MIGRAÇÃO SEM COMANDOS

Importar banco antigo (.db)

Use esta opção para trazer os resultados do BI que estava no seu computador. A conta principal pode selecionar o arquivo bloodline.db antigo diretamente nesta página.

A importação não substitui o banco online nem os administradores. O sistema faz backup, preserva os dados existentes e impede resultados duplicados. Se houver conflito, a operação é cancelada.

Antes de escolher o arquivo, feche o BI antigo no computador para garantir que os resultados estejam salvos nele. Tamanho máximo: 64 MB. Não envie esse arquivo ao GitHub.
